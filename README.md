# Jedit-Pro-docs

Jedit Pro (macOS テキストエディタ) のユーザー向け公開ドキュメント。

- 公開 URL: <https://cometheart314.github.io/Jedit-Pro-docs/>
- 製品本体: <https://github.com/cometheart314/Jedit-Pro> (private)
- 無料版 Jedit: <https://github.com/cometheart314/Jedit-open>

## 構成

```
docs/
├── index.html         # ブラウザ言語で ja/ または en/ へ自動リダイレクト
├── style.css          # 共通スタイル
├── appicon.png        # アプリアイコン
├── ja/
│   ├── index.html     # Jedit Pro トップ (日本語)
│   ├── privacy.html   # プライバシーポリシー
│   └── mcp.html       # Claude Desktop 経由で Jedit Pro を使う
└── en/
    ├── index.html
    ├── privacy.html
    └── mcp.html
```

`docs/` フォルダが GitHub Pages の公開ソースです。
