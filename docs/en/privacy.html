Privacy Policy

Privacy practices for Jedit Pro

Overview

Jedit Pro (the "App") is a macOS application provided by Artman21 Inc. ("we", "us"). We respect user privacy. The App does not collect, store, or transmit any personal information to third parties.

Data Collection

Jedit Pro does not collect any of the following:

  • Personally identifiable information (name, email address, etc.)
  • Location data
  • Contacts or calendar data
  • Document contents
  • Contents of files targeted by multi-file find & replace, or the search/replace strings used
  • Usage statistics such as how often the application is launched

Network Communication

Jedit Pro does not connect to our servers. It never records application launches or transmits usage statistics. The network is used only in response to your own actions, in the following cases:

  • When a Markdown document references an image at an external URL, that image is fetched in order to display it
  • When you configure text-to-speech to use Google Cloud Text-to-Speech (see “Text-to-Speech” below)
  • When you enable the MCP server (see “MCP Server and AI Client Integration” below; traffic stays within your own Mac)

Text-to-Speech

By default, text-to-speech uses the speech synthesis built into macOS and involves no network communication. Only if you enter your own Google Cloud Text-to-Speech API key in Preferences is the text to be spoken sent to Google's servers, which return the synthesized audio. That communication is governed by Google's privacy policy and terms of service. The API key is stored locally on your Mac and is never transmitted to us. If you prefer not to send text to an external service, simply leave the API key blank.

iCloud

Jedit Pro provides the ability to sync documents through iCloud Drive. Data stored in iCloud is managed under Apple's privacy policy. We do not access data stored in iCloud.

Files Accessed by Multi-File Find & Replace

The multi-file find & replace feature operates only on files and folders explicitly specified by the user. These files are read or written locally for the search and replace operation; they are never transmitted externally. Search strings, replacement strings, and history are stored only in the local storage of your Mac.

MCP Server and AI Client Integration

If you choose to enable it, Jedit Pro can run a local MCP (Model Context Protocol) server. When this feature is enabled:

  • The server binds to 127.0.0.1 (loopback) only and is reachable solely from within the same Mac. It cannot be accessed over the Internet.
  • Connections require Bearer token authentication (auto-generated).
  • Jedit Pro itself does not connect to any AI vendor servers (Anthropic, OpenAI, etc.). The AI client (such as Claude Desktop) is what communicates with the vendor.
  • Results returned by tool invocations (i.e., the contents of your open documents) may be transmitted to the AI vendor via that AI client. Please refer to each client's privacy policy for details.
  • When handling confidential documents, we recommend closing them or disabling the MCP server.

Local Data

App settings (font size, display preferences, search history, presets, etc.) are stored only in the local storage of your Mac and are not transmitted externally.

Contact

For questions regarding privacy, please contact Artman21 User Support at support@artman21.co.jp.
