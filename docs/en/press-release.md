# Press Release

**For Immediate Release**

## Jedit Pro v1.0, a Text Editor for macOS, Now Available on the Mac App Store

— Multi-file find &amp; replace, document comparison, and Aozora-style ruby and emphasis dots: the upgraded edition for long-form writing in Japanese —

**Tokyo, July 31, 2026** — **Artman21 Inc.** announced the release of **Jedit Pro v1.0**, a text editor for macOS, on the Mac App Store. Jedit Pro is the upgraded edition of the free **Jedit**, adding the advanced editing features inherited from the legacy **Jedit Ω**. The app itself is a free download, and all features are free to try for 7 days from first launch.

Jedit Pro is built for people who work with long manuscripts and large numbers of files, or who deal with Japanese typesetting and text processing every day. It renders Aozora-style ruby and emphasis dots directly in the editor, searches and replaces across multiple folders, compares documents side by side, and integrates with AI clients.

App Store: <https://apps.apple.com/app/jedit-pro/id6764817834>

### Key Features

- **Multi-file find &amp; replace** — Search across multiple folders, jump to any hit from the results list, and replace in batch. Multiple find/replace pairs can be applied in a single pass
- **Document comparison** — Place two documents side by side with color-coded differences. Comparison against a previously saved version is also supported, and double-clicking a difference jumps to the corresponding place in the document
- **Smart Index** — Automatically extracts headings into a sidebar outline, with customizable extraction rules for Markdown, HTML, programming languages, and more
- **A full set of text-processing tools** — Hard line wrapping, sorting by line or word (including Japanese reading order and numeric order), Unicode normalization (NFC/NFD/NFKC/NFKD), half/full-width conversion, duplicate line removal, kanji radical detection and conversion, and encoding compatibility checks
- **Syntax coloring and customizable key bindings** — Keyword coloring for major languages with user-defined additions, plus freely configurable menu shortcuts and key bindings, including Emacs-style key bindings
- **AI client integration (MCP server)** — AI clients such as Claude Desktop can read and edit the documents open in Jedit Pro. The connection is restricted to loopback on the same Mac and requires an access token
- **Aozora-style ruby and emphasis dots** — Aozora Bunko annotations such as `｜漢字《かんじ》` are rendered as actual ruby text in the editor. Ruby appears in the editor, in print, and in HTML export, in both vertical and horizontal writing. Nine styles of emphasis dots are supported, including dots placed on the opposite side and combined use with ruby
- **HTML export for digital publishing** — Export documents containing ruby and emphasis dots as HTML suitable for use as EPUB source
- **High-quality read aloud** — In addition to the standard macOS voices, Google Cloud Text-to-Speech voices are supported (an API key is required)

Everything in the free Jedit — vertical and horizontal writing, page layout view, extensive character encoding support with auto-detection, rich text, Word and Markdown, iCloud sync, AppleScript, and printing with headers and footers — is also available in Jedit Pro.

### Relationship to Jedit Ω

Jedit Ω was loved by many users as a powerful text editor for the Mac, but its codebase had grown old and could no longer keep up with newer versions of macOS. **Sales and support for Jedit Ω ended at the end of November 2025.** The new Jedit and Jedit Pro are successor editors **rewritten from scratch, with AI (Claude Code) adopted across the entire development process**, using Jedit Ω as a reference.

The free Jedit, released in April 2026, was deliberately narrowed to the features everyone needs daily, and a number of Jedit Ω features were not reimplemented. Jedit Pro now provides those features: multi-file find and replace, document comparison, the Tools menu commands, encoding compatibility checks, syntax coloring, Smart Index, and menu shortcut and key-binding customization.

Jedit Pro also adds features that Jedit Ω never had: Aozora-style ruby and emphasis dots, HTML export for digital publishing, high-quality read aloud via Google Cloud Text-to-Speech, and a built-in MCP server for AI clients.

### Pricing

The app itself is a free download, and all Pro features are free to try for **7 days** from first launch. No payment is required during the trial, and no cancellation is needed. To continue afterwards, choose one of:

- **Yearly Subscription** — JPY 3,000 per year, automatically renewing
- **Lifetime License** — JPY 5,000, one-time payment, no renewal (covers version 1.x)

The yearly subscription renews automatically unless auto-renew is turned off at least 24 hours before the end of the current period. It can be managed or cancelled at any time in the App Store or in System Settings &gt; Apple Account &gt; Subscriptions.

### Privacy

Jedit Pro stores document contents, search strings, and all settings on the user's own Mac and sends nothing off the device. Even with AI client integration enabled, communication is confined to the same Mac.
