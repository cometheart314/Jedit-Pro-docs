概要

Jedit Pro は、macOS 向けのテキストエディタです。無料版 Jedit のすべての機能に、旧版 Jedit Ω 由来の高度な編集機能を加えた上位版で、長文原稿や大量のファイルを扱う方、日本語の組版・テキスト処理を日常的に行う方に向けた構成です。

青空文庫形式のルビ・傍点の実描画、複数フォルダをまたぐ検索・置換、書類の差分比較、電子出版向けの HTML 書き出し、そして AI クライアントと連携する MCP サーバー機能を搭載しています。

アプリ本体は Mac App Store にて無料で提供され、初回起動から 7 日間はすべての機能を無料でお試しいただけます。継続利用は年額 3,000 円のサブスクリプション、または 5,000 円の買い切りライセンスです。

Pro 専用の主な機能

青空文庫ルビ・傍点

｜漢字《かんじ》の注記を実際のルビとして描画。縦書き・横書きのどちらでも、編集画面・印刷・HTML 書き出しに反映。傍点は 9 種類に対応。

マルチ検索・置換

複数のフォルダを横断して検索し、結果パネルからジャンプ・一括置換。マルチペアの一括置換にも対応。

書類の比較

2 つの書類を左右に並べて差異を色分け表示。保存済みバージョンとの比較や、差異のダブルクリックで該当箇所へジャンプ。

スマートインデックス

サイドバーに見出し一覧を自動生成。抽出ルールはカスタマイズ可能で、ブックマークへの取り込みにも対応。

シンタックスカラーリング

プログラミング言語やマークアップ言語のキーワードを色分け表示。ユーザー定義の追加も可能。

キーバインドのカスタマイズ

メニューのキーボードショートカットとテキスト編集時のキー操作を自由に変更。Emacs 風キーバインドの再現も可能。

AI クライアント連携 (MCP)

Claude Desktop などの AI クライアントから、開いている書類を読み書き。通信は同一 Mac 内のループバックに限定し、アクセストークン認証を必須とする。

電子出版向け HTML 書き出し

ルビや傍点を含む書類を、EPUB 制作の元データとして使える HTML に変換。

ツールメニュー

強制改行、ソート、Unicode 正規化、半角⇔全角変換、重複行処理、漢字部首の検出と変換、文字コード互換性チェックなど。

無料版 Jedit の基本機能（縦書き・横書き、ページ表示、文字コード対応と自動判定、リッチテキスト、Word・Markdown、iCloud 同期、AppleScript、印刷）も、すべて Jedit Pro でご利用いただけます。

Jedit Ω・無料版 Jedit との関係

Jedit Ω は、Mac 用の高機能エディタとして多くのユーザーに愛用されてきましたが、コードベースが古くなり、新しい macOS への追従が困難になったため、2025 年 11 月末をもって販売およびサポートを終了しました。新しい Jedit / Jedit Pro は、Jedit Ω をベースに、AI（Claude Code）を全面的に採用して全くゼロから書き直された後継エディタです。

2026 年 4 月に公開した無料版 Jedit では、誰もが日常的に必要とする機能に絞り込み、一部のユーザーしか使わない機能の再実装は見送りました。Jedit Pro は、そこで見送られた Jedit Ω の機能を提供する上位版です。

Jedit Pro で提供される Jedit Ω の機能

  • マルチファイル検索 / 置換
  • 書類ファイルの比較機能
  • Jedit Ω ツールメニューの各種機能
  • 文字コード互換性チェック
  • シンタックスカラーリング
  • スマートインデックス
  • メニューショートカットのカスタマイズ
  • キーバインドのカスタマイズ

Jedit Ω にもなかった新機能

  • 青空文庫形式のルビ・傍点（編集画面・印刷・書き出しに反映）
  • 電子出版向けの HTML 書き出し
  • Google Cloud Text-to-Speech による高品質な読み上げ
  • AI クライアントと連携する MCP サーバー機能

プライバシー

Jedit Pro は、書類の内容・検索文字列・各種設定をすべてお使いの Mac 内に保存し、外部に送信しません。AI クライアント連携機能を有効にした場合も、通信は同一 Mac 内のループバック接続に限定されます。
